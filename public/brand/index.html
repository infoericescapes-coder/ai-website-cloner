01

The idea

Every Eric Escapes product is a file pulled from the archive, not a boxed product. Machine-set monospace metadata (file numbers, catalogue stamps, conservation notes) sits over warm, human photography. The tension between the two is the brand: the ghost in the machine. The photograph is always the artefact; everything else is the sleeve it's archived in.

05

The vocabulary

Five elements build every Eric Escapes surface. Use them sparingly; a surface needs two or three, never all five at once.

File · EE-NN

Folder tab · slanted right edge · names the file

Corner brackets · frame a panel like a viewfinder

Specimen mat · pale border #e9e7dc · caption printed ON the mat, never on the photo · photos never overlap text

Catalogue numbers · FILE EE-nn / CAT. EE-XXX-nn · increment per release · EE-01 Chaos to Calm · EE-02 Visual Diary · EE-03 Sydney Chrome

Conservation stamps · "Conservation copy / Do not discard" · the archive taking itself seriously so the photos don't have to

06

Photography

Photography is the only saturated, living element on any surface. The crop law: every frame holds its subject deliberately (tune the crop per image, pre-crop when the window can't reach the subject, and never use a motion-blurred frame at mat size). Night neon, quiet streets, harbour light: the frames below are the register.

07

Voice

Australian, conversational, honest. Short paragraphs. A mate talking over coffee, not a committee. Self-deprecating but confident underneath. Anti-gatekeeping without being angry about it. Published copy never uses em dashes, never uses marketing superlatives, and always grounds ideas in a real place, camera, or moment. The register in one line: "the door, not the destination."
